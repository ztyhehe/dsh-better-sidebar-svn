## 1. 目标

在 v0.1.0 基础上落实三组改进：

1. **工程规范化**（通用/工程全部 + 两共同中的 CHANGELOG/测试/文档）
2. **UI 可用性补全**（diff 搜索/过滤 + svn 缺失降级提示）
3. **能力补齐**（svn:ignore 管理）

- 保持与 dsh-better-sidebar 内置 Git 面板交互对称，不破坏 v0.1.0 API 兼容性。
- 所有新增路由遵循既有 `/sidebar/api/svn.*` 命名与 trust-fence/JSON 响应约定。
- 危险写操作继续走确认弹窗。

## 2. 现状事实（据源码）

- host 半 `src/index.ts` 注册 13 个精确路由（status/diff/add/revert/stage/unstage/commit/update/log/cat/info/resolve/revertRevision）。
- `src/svn.ts` 所有命令带 `--non-interactive --no-auth-cache`，输出 `--xml`；`runSvn` spawn `svn` 二进制，`svn` 不存在时抛 `SvnCommandError`，无友好降级提示。
- client 半 `SvnView.tsx` / `SvnDiffTab.tsx`。`SvnDiffTab` 仅静态渲染 `parseUnifiedDiff` 结果，顶部只有刷新按钮，无搜索/过滤。
- 无任何 `svn:ignore` 读写能力（无 `propget/propset svn:ignore` 封装）。
- `parseUnifiedDiff`、`svn.ts` 的 XML 提取函数均为纯函数，无单测。
- `.gitignore` 注释明确 `lib/` 必须提交（git 直装用）。`package.json` 有 `typecheck`/`build` 脚本，无 CHANGELOG。

## 3. 需求细节

### 3.1 通用/工程

#### 3.1.1 写 CHANGELOG（最优先）
- 新增 `CHANGELOG.md`，`[0.1.0] - 2026-08-19` 为首版，curated 分组。素材取自 v0.1.0 tag message。

#### 3.1.2 .gitignore 核对
- 当前较完整（`node_modules/`、`*.log`、`.DS_Store`，lib/ 除外）。核对无本机路径/密钥泄漏，按要求补 `*.local*`、`.env*` 等。

#### 3.1.3 统一标签与版本联动
- 当前手动打 tag。建议向 `package.json` 加 `version` 脚本钩子（如 `preversion`/`postversion` 自动打 tag 并推），保证版本号与 tag 不脱节。本模块有 TS 构建，`npm version` 前应跑 `typecheck`。

### 3.2 dsh-better-sidebar-svn 专属

#### 3.2.1 diff 无关键词/文件过滤搜索
- 现状 `SvnDiffTab` 静态渲染大 diff 无可搜索/过滤。
- 需求：
  - 关键词搜索：标题栏加搜索框，命中行高亮 + `n/m` 计数 + Enter 上下跳转；可选自动折叠未命中 hunk。
  - 路径过滤：标题栏加路径子串过滤，只渲染匹配的文件区块。
  - 两者共用一套"标题栏输入框 + 重渲染过滤结果"结构。
  - 纯 client 前端改动，不新增后端路由、不增网络往返（diff 文本已整体拉取）。

#### 3.2.2 shell `svn` 依赖无降级提示
- 现状系统无 `svn` 二进制时所有操作抛 `SvnCommandError("cannot run svn: ...")`，用户看到的是无意义的报错。
- 需求：host 启动时（或首次 `apply` / 首个请求）探测 `svn` 存在性；缺失时返回友好错误（code 如 `svn-missing`，message 提示"系统未安装 svn 命令行，请安装后重试"），并在前端面板展示可读提示而非空白报错。
- 前端 API 侧可将 `svn-missing` 映射为友好文案。

#### 3.2.3 svn:ignore 管理
- 现状无任何 `svn:ignore` 读写。
- 需求：
  - 新增 `svn.ignoreGet` / `svn.ignoreSet` 两个路由：`ignoreGet` 封装 `svn propget svn:ignore <cwd>`；
  - `ignoreSet` 语义：非空规则 → `svn propset svn:ignore -F <临时文件> <cwd>`（多行规则走临时文件，避免命令行转义/长度问题）；规则全部清空 → `svn propdel svn:ignore <cwd>`（`propset` 空串不等价于删除属性）。
  - client 面板加"忽略规则"模态框：读当前目录 `svn:ignore`、编辑（换行分隔模式）、保存。
  - 保存后刷新状态区，被忽略的未版本控制文件即刻从面板消失。
  - UI 提示"规则仅作用于当前目录、不递归"，避免用户误解。
  - 写操作锁定当前 `cwd` 的 `realpath`，避免绝对路径写到仓库外。

### 3.3 两者共同（本模块适用）

#### 3.3.1 补测试
- 为 `parseUnifiedDiff` 与 `svn.ts` 的 XML 提取函数（`extractTag`/`extractAttr`/`extractEntries`/`extractChangelistSpans`/`extractLogEntries`/`extractPaths`/`extractInfoEntry`/`parseLog`）补单测。
- 用 Vitest（`pnpm` 工程）+ `tsx`/默认 loader 或 Node test runner，实施时选定。

#### 3.3.2 类型 / 错误边界
- client 无 React `ErrorBoundary`；API 错误已处理但渲染层异常会白屏。
- 需求：给 `SvnView` / `SvnDiffTab` 包一层 `ErrorBoundary`，渲染失败时显示可读错误占位而非整面板白屏。

#### 3.3.3 文档补全
- 两插件无 CHANGELOG（本模块在 3.1.1 已含）。
- README 补：新增 diff 搜索/过滤、svn:ignore 管理、svn 缺失降级提示的说明；更新 API 路由表加入 `svn.ignoreGet`/`svn.ignoreSet`。

## 4. 非目标（明确不做）

- 不做分支/标签浏览（BRANCH/TAG 切换）与 `svn switch`——高面积、写侧有副作用，列入后续批次，不在本 spec。
- 不改变 `svn` CLI 调用约定、trust-fence、JSON 响应格式。
- 不处理 unipet-dsh 的任何内容（那是另一工程）。
