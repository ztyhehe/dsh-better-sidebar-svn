## 风险

| 风险 | 影响 | 处置 |
|---|---|---|
| 区间写 `^0.2.0-rc.1` 单值会丢掉 0.1.7 线 | 老用户被拦 | 用并集 `^0.1.7-rc.1 \|\| ^0.2.0-rc.1`，并用矩阵断言 0.1.7 线仍 OK |
| 误放到 `0.3.x` | 未来大版本未验证即加载 | 矩阵断言 `0.3.0` REJECT |
| 沙箱内 `react` 解析不到导致 `Input` 回调 implicit any 的**假报错** | 误判不兼容 | 把 0.2.x 包**复制**（而非软链）进沙箱，使 TS 向上解析到沙箱根的 `react`；修正后 0 error |
| 抬 `devDependencies` 需联网重装（本机 npm 缓存 EPERM） | 无法验证 | 本次不动 devDeps；构建产物在两条线下一致，已足够 |
| 改了 peer 但用户 profile 仍钉 `#v0.3.0` | 现场仍不加载 | 提交+tag 后由人工推送并更新 profile 依赖引用（本次不做） |
