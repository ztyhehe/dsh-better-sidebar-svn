## 风险

| 风险 | 影响 | 应对 |
|---|---|---|
| `pnpm install` 拉到非预期版本（peer 解析） | 编译用错类型，改名被判错 | 阶段 1.3 显式 devDependencies 钉版本；1.4 打印实际版本核对 |
| 内联字形与内置观感不一致 | 视觉不统一，需返工 | 直接复制 `lib/client.js` 中 `VscGitCommit` 的 `viewBox`/`path` 原文，不做手绘 |
| 覆盖 profile 里的 `lib/` 后下次 `pnpm install` 被还原 | 线上效果被冲掉 | 在 README/交接说明中记明；根治需提交推送后重装或改 `link:` |
| 误改 host 半导致路由回归 | 面板整块不可用 | 本次不改 host 半；部署前备份、可一键回滚 |
| 旧 devDeps 仍被缓存 | 再次 build 又产出旧名 | 阶段 5.4 对重建产物做旧名 Grep 作为门禁 |
